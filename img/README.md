# Icon source artwork

[Flaticon](https://www.flaticon.com/free-icon/) and are covered by the **Flaticon Free License**,
not by the Apache-2.0 licence that covers the rest of this repository. The Flaticon licence requires
attribution to the original author wherever the icons appear.

Everything under `src/main/resources/svg/` and `src/main/resources/images/` is derived from these
files, so the same terms follow them into the built JAR.

See the repository [NOTICE](../NOTICE) for the full attribution, and the top-level
[README](../README.md#icons) for how the PNGs are regenerated.
